# 💬 Nebula AI 使用说明

> **🚧 开发中**
>
> Nebula AI 尚未正式发布。本文档基于设计目标编写，实际功能以 v0.1 Alpha 发布版本为准。

---

## 全局呼出

默认快捷键 **Ctrl + Alt + S**：

- 按下后，侧栏从屏幕**右侧滑出**
- 再次按下（或点击空白处 / Esc）收起
- 支持在游戏中随时呼出，不打断当前操作

> 后续版本将支持在设置界面自定义快捷键。

---

## 界面布局（规划）

- **悬停置顶**：作为置顶侧栏悬浮于游戏之上
- **多角色群聊**：可在同一会话中切换/混入多个角色
- **流式输出**：模型回复逐字输出，可随时停止

---

## 常用操作（规划）

| 操作 | 方式 |
|:---|:---|
| 呼出/收起侧栏 | `Ctrl+Alt+S` 或 Esc |
| 新建会话 | 侧栏顶部「+」 |
| 切换角色 | 会话成员选择器 |
| 停止生成 | 回复期间点击「停止」 |

---

## 配置说明（规划）

- **模型/服务地址**：支持配置本地或远程 API 端点
- **快捷键**：可在设置中修改全局热键
- **启动行为**：可选开机自启（推荐，以实现常驻后台）

---

## 已知限制（规划）

- Wayland 下的全局热键与置顶行为依赖桌面环境支持（KDE Plasma 下表现最佳）
- 首次呼出需等待后端进程启动（约 1–3 秒）
