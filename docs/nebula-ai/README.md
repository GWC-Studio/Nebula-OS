# Nebula AI

拟真 AI 聊天客户端，专为桌面集成设计。

> **🚧 开发中**
>
> 本项目正在积极开发中，预计 v0.1 Alpha 将在 2026年9月 发布。

---

## 🎯 设计目标

- **全局呼出**：通过快捷键 (Ctrl+Alt+S) 从屏幕右侧滑出
- **悬浮侧栏**：不干扰游戏，始终置顶
- **拟真聊天**：多角色群聊、流式输出、自定义角色
- **轻量常驻**：后台占用极低

---

## 🔧 技术栈

| 组件 | 技术 |
|:---|:---|
| 前端 | HTML + CSS + JavaScript |
| 后端 | Python (FastAPI) |
| 桌面集成 | PyQt6 + QtWebEngine |
| 全局热键 | pynput |
